# Exercises

Material students can hand in and instructors can grade, beyond the practice tasks inside each module.

| File | What it is | For |
|------|-----------|-----|
| [exercise-bank.md](exercise-bank.md) | 40 graded exercises tagged by module and difficulty, each with a deliverable and marking points | students and instructors |
| [self-check-quizzes.md](self-check-quizzes.md) | Five questions per module with hidden answers, for revision | students |
| [instructor-notes.md](instructor-notes.md) | What good answers look like, common weak answers, and traps in each exercise | instructors |

**Difficulty:** ★ 20-30 minutes, no setup · ★★ about an hour, may need an AI account · ★★★ several hours, needs module 7 tools.

**Deliverables** are Markdown files unless stated. Use the templates in [`../templates`](../templates): most exercises ask for a prompt log or a verification log.
