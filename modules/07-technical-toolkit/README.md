# Module 7: The Technical Toolkit

> Plain-text, open tools turn AI from a chat window into a working partner.

## Why these tools?

What these tools share is that they are **plain-text and open**: the formats AI models read and write most fluently. Many people become highly AI-proficient without them, but for anyone who wants to build things, they are the core.

## The toolkit at a glance

| Tool | Why it matters for AI | Where to start | Guide |
|------|----------------------|----------------|-------|
| **Python** | The main language of AI, data, and automation; lets you read and judge AI-written code | Variables, loops, functions, then pandas and requests | [python.md](python.md) |
| **Command line** | Where developer tools and AI agents operate | Navigating folders, running scripts, installing packages | [command-line.md](command-line.md) |
| **Git and GitHub** | A reviewable, reversible history of every change, including an agent's | Commit, push, pull, then branches and pull requests | [git-and-github.md](git-and-github.md) |
| **Markdown** | The native format of prompts, AI output, and documentation | Headings, lists, links, and code blocks | [markdown.md](markdown.md) |
| **SQL** | How most of the world's data is queried | SELECT, WHERE, GROUP BY, JOIN | [sql.md](sql.md) |
| **APIs and data formats** | Call AI models from your own code; JSON and YAML carry the data | One request to an AI API from Python | [apis-and-data-formats.md](apis-and-data-formats.md) |
| **LaTeX or Typst** | Standard for mathematical and scientific writing | Only if your field requires it | [latex-and-typst.md](latex-and-typst.md) |

## Tiers

- **Core (learn together):** Python, command line, Git and GitHub, Markdown. Python runs from the command line, Git tracks your files, and Markdown documents them.
- **Second tier (role-dependent):** SQL, APIs, and data formats.
- **Specialized:** LaTeX or Typst, essential in research and academia, optional elsewhere.

## Habits that apply to every tool

- **Learn by building.** Use each tool on a real task you care about, not only on abstract exercises.
- **Use AI as a tutor, not a substitute.** Ask it to explain, not just to produce.
- **Practice a little every day** rather than in occasional long sessions.
- **Combine tools early.** A Python script that queries data with SQL, tracked in Git and documented in Markdown, teaches four tools at once.
- **Share your work on GitHub.** It creates accountability and a portfolio at the same time.
