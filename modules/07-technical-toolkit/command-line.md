# The Command Line

## Why it matters

The command line (a terminal running bash, zsh, or PowerShell) is where developer tools and AI coding agents operate. Understanding it lets you follow what an agent is doing instead of approving actions blindly.

## Learn first

| Task | macOS / Linux | Windows PowerShell |
|------|---------------|--------------------|
| Where am I? | `pwd` | `pwd` |
| List files | `ls` | `ls` or `dir` |
| Change folder | `cd folder` | `cd folder` |
| Go up one folder | `cd ..` | `cd ..` |
| Make a folder | `mkdir name` | `mkdir name` |
| Show a file | `cat file.txt` | `cat file.txt` |
| Run Python | `python3 script.py` | `python script.py` |
| Get help | `man command` | `Get-Help command` |

## Tips for becoming proficient

- **Do one routine task a day in the terminal** instead of the graphical interface, such as creating folders or moving files.
- **Use Tab to autocomplete** file and folder names, and the up arrow to repeat earlier commands.
- **Keep a personal cheat sheet** of commands you use, written in Markdown.
- **Before running any command an AI suggests, ask what it does**, especially if it deletes, moves, or overwrites files (`rm`, `mv`, `>`).
- **Use the terminal built into VS Code** so your editor and command line are side by side.

## Practice

1. Using only the terminal, create a folder called `ai-course`, with subfolders `notes` and `code`.
2. Create a Python file, run it from the terminal, and redirect its output to a text file with `>`.
3. Ask an AI to explain every part of a command you don't recognize before you run it.
