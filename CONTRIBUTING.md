# Contributing

Thank you for helping improve this course. Students and instructors are both welcome to contribute.

## Ways to contribute

- **Fix an error:** typos, broken links, or outdated information.
- **Add an exercise:** a practice task that worked well in your class, in the format of the [exercise bank](exercises/exercise-bank.md) (task, deliverable, marking points).
- **Add a worked example:** a real episode - the prompt, the output with its errors, how they were found - in the format of [examples/worked-examples](examples/worked-examples/README.md). Remove anything personal first.
- **Add a prompt:** to the [prompt library](examples/prompts/README.md), with a sentence on why it works.
- **Share a translation:** add translated modules in a folder such as `translations/kk/` or `translations/ru/`.
- **Suggest an improvement:** open an Issue describing what you would change and why.

## How to submit a change

1. Fork this repository.
2. Create a branch with a short descriptive name, for example `fix-module-3-typo`.
3. Make your changes in Markdown, following the style of existing modules.
4. Commit with a clear message explaining *why*, for example `Clarify context window example in module 3`.
5. Open a Pull Request and describe what you changed.

## Style guide

- Write in plain, direct language. Short sentences, concrete examples.
- Keep each module's structure: learning goals, key ideas, practice, reflection.
- Never include API keys, passwords, or personal data in any file.
- When you use AI to help write a contribution, check every fact yourself. That is the point of module 2.
