# Prompts for writing

## A message that needs sending

```
Write a [email / message] to [recipient and their role] asking for [the specific outcome].
Context: [the situation in two or three sentences, including anything the recipient already knows].
Constraints: under [n] words; [formal / friendly]; do not invent details - if something is missing, mark it as [BRACKET] for me to fill; do not mention attachments unless I say there are some.
End by [proposing a specific next step].
```

*Why "do not invent details" matters:* see worked example 1, where the AI added a non-existent attachment.

## Feedback on a draft (without rewriting it)

```
Here is my draft [abstract / section / essay]: [paste]. It is for [audience] and must [purpose].
Do not rewrite it. Give me: (1) the one sentence that states the main point, or say that none does; (2) three specific weaknesses, each with the line it occurs in; (3) one thing that works and why.
```

*Why:* you keep ownership of the text and learn where it fails. Rewrites hide what was wrong.

## Edit for clarity, keep my voice

```
Edit the text below for clarity and grammar only. Keep my wording and sentence order wherever they are correct. Do not add content, do not change technical terms, do not change the tone.
Return the edited text, then a list of every change you made with a one-phrase reason.
```

*Check:* read the change list. Any change you did not ask for is a decision you must make.

## Abstract from a finished report

```
Write a 200-word abstract of the report below for [journal / course / conference]. Structure: motivation (one sentence), method (two), main results with numbers taken ONLY from the report (two or three), significance (one). Do not add any number or claim that is not in the text.
<report>[paste]</report>
```

*Check:* every number in the abstract must appear in the report. Search for each.

## Structure before prose

```
Give me a five-bullet outline for a [n]-word [section] on [topic] for [audience], based on these points: [bullets]. Do not write the section yet. Mark which bullet carries the main argument.
```

Then, after you have edited the outline: "Now write the section from this outline." (Worked example 6.)

## Translate and back-translate

```
Translate the text below into [language] for [audience]. Keep technical terms as [convention: English in brackets / standard translations]. Then translate your translation back into English, and list any place where the back-translation differs in meaning from the original.
```

## Cover letter or statement

```
Draft a [cover letter / statement of purpose] for [programme / job], under [n] words, from these facts about me: [bullets - only true facts]. Match these points from the posting: [bullets]. Do not add achievements I have not listed. Plain language, no clichés such as "passionate" or "I am writing to express".
```
